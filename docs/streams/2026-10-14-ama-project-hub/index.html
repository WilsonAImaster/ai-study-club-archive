1. 30秒看懂這場

自由工坊是什麼？

台灣AI社群自己做的開源平台。你可以把它想成一間「AI工具公會大廳」：每個公會都有一套別人做好、可以直接拿來用的工具（技能書）。

不會寫程式也能參與？

可以。到GitHub發一個Issue，就像在意見箱投一張紙條：「這裡不好用」。有人回覆、討論完，再交給AI去改程式。

Project Hub在解決什麼？

同時用好幾個AI的人最痛的就是「額度用完要換工具，又要重講一次進度」。它讓AI自己交接，像換班的護理師會寫好交班單。

4. 自由工坊：社群自己的AI工具平台

一句話：大家把自己做的AI工具放上來，按「公會」分類，誰都能拿去用，也能一起改。Hao0321表示網站功能全部免費。

想參與開發？發一個Issue就好

  • AI寫程式已經很快，你不用學到很深，但要有基本概念，才知道該叫AI往哪裡改
  • 流程是：人先在Issue討論 → 討論完再請AI一起進來 → 開始改程式
  • 不用怕問題太小。當天的例子：有人提「圖示太小」，另一個人提「高度沒對齊」，其實是同一個問題，最後合併成一個PR（程式修改申請）一次送出，省下排隊等自動檢查的時間

做產品的心法：第一眼就要看懂

  • 原本介面太「工程師風」，現在改成從年輕人到長輩，第一眼就知道怎麼註冊、怎麼用
  • Hao0321的原則很簡單：越簡單、越直覺越好

公會＋技能書

  • 大約25個公會，例如影片媒體自動化、開發、成長行銷、音樂、資安、電商、廣告、線下活動
  • 每個公會綁一套技能書，都是夥伴做的開源工具，有作者，也可以一起開發。介面做成像遊戲一樣，比直接逛GitHub好懂
  • 加入公會有專屬聊天室，也可以申請開自己的公會

當天還示範了這些

  • Editkin自動剪輯器：丟影片進去、選旅遊或美食這類模板、填標題和重點，就自動剪好
  • AR衣服名片（新提案）：掃一下衣服或紙上的圖案，手機就跳出特效或你的個人名片，線下活動認識人很方便

為什麼要做這個平台

  • 幫有貨源的夥伴繞過通路壓力：大家一起推薦，賣出就分潤
  • 不會被亂鎖帳號、不是一言堂，好作品發出來就會被看見

5. Project Hub：讓好幾個AI自己交接工作

原始碼：kieiken/project-hub

一句話：把Claude Code、Codex、Gemini這些AI收進同一個視窗，一個專案一個工作區，某個AI額度用完，就自動換下一個AI接著做。

它怎麼省錢：走訂閱，不走API

它用的是你已經付費的訂閱方案（例如Claude、ChatGPT的月費），不是另外按用量計費的API。差別就像吃到飽和單點：訂閱是月費固定，API是用多少算多少。所以不會多出一筆帳單，但至少要有付費訂閱，免費方案不能用。

額度用完，自動換人接手

  • 可以先設好「查資料用A、寫程式用B、檢查用C、寫文章用D」，下指令時它自己挑
  • 某個AI的5小時額度用完，會自動切到另一個AI繼續做
  • 交接時，前一個AI會自己寫好交班單：目的、要讀哪些檔、要做什麼、要交出什麼
  • 還有一個特殊模式：額度快重置時，先把剩很多的那家用完，不浪費

FreeTalk：還沒想好要做什麼，也能先聊

  • Claude Code和Codex平常一定要先選資料夾才能開始，FreeTalk不用
  • 聊一聊覺得可以做，一鍵轉成專案
  • 對話太長會自動整理；超過30萬token（AI計算字數的單位）會提醒你，30天沒整理會自動打掃

幾個很貼心的小設計

  • 刪對話會連檔案一起清：一般刪對話只刪紀錄，AI做出來的暫存檔還留在電腦裡佔空間；這裡會一起丟進垃圾桶，後悔還救得回來
  • 換AI只要打「繼續」，不用重講前面的內容
  • 四種送出鍵：插隊（先做新的）、追加（在進行中的工作加條件，像買蛋順便買牛奶，不用跑兩趟）、排隊（等前一個做完）、一般送出
  • 標題顏色看狀態：黃色等你回覆、紅色AI處理中、白色完成

Mini最愛的功能：用手機遠端看進度

透過Tailscale連回家裡的電腦，手機瀏覽器就能看所有專案的進度，不用裝App。Tailscale你可以想成家裡電腦專屬的私人通道，只有你自己的裝置走得進去。前提是家裡電腦要開著。

還在開發的功能

  • AI圓桌會議：勾好幾個AI，指定一個當主持人，討論幾輪後幫你總結
  • Idea Book：想法和bug先丟進清單，不要同時開太多分支改程式，免得最後整合卡關

6. 問答精選

  • 要什麼訂閱？只支援訂閱方案，至少要付費版；只訂Claude，就只用Claude也可以
  • 舊專案怎麼接進來？用FreeTalk告訴它資料夾在哪、要接哪個案子，找到後一鍵轉成專案
  • 安裝卡住？多半是Mac的資料夾讀取權限沒開

7. 看完想動手，可以從這裡開始

  1. 到自由工坊註冊，加入一個有興趣的公會，領一本技能書來用
  2. 用了覺得哪裡不順，到GitHub發一個Issue，說清楚「哪裡不好用、你希望怎樣」就夠了
  3. 如果你同時在用好幾個AI、常常卡額度，可以留意Project Hub的Windows版消息
