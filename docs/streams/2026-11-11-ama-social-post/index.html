1. 30秒看懂這場

為什麼直接叫AI寫，貼文會沒流量？

AI寫的是「全世界的平均值」，不是為你的帳號量身訂做。Social Post Skill像一本寫作規則手冊：用真的有流量的貼文整理出格式，讓AI照你的口氣、照平台喜歡的方式寫。

FB和Threads差在哪？

Threads像抽獎，隨時可能爆紅，但粉絲黏著度低；FB像開店，要持續經營，但認識你的人會一直看到你。兩邊的眉角不一樣，Hao0321分享了自己實測幾個月的心得。

開源工具可以隨便拿來改嗎？

不一定，要看授權。最簡單的記法：作者寫MIT或Apache 2.0，基本上隨你用；寫GPL，你改完也要開源分享回去。

4. Social Post Skill：讓AI照你的口氣、照演算法寫貼文

Skill本身：Hao0321/claude-skill-social-post

一句話：它不是保證爆文的魔法，而是讓平台更快認識你，更快把你的內容推給對的人。JasonC說，可能要一個禮拜到一個月，平台才會認識你的帳號。

開始方式：把一段提示詞貼給你的AI

  • 用你平常在用的AI就可以：Claude、Codex、ChatGPT、Antigravity都行。當天有人回報Gemini讀不到，可以先換一個
  • JasonC建議不同模型都試試看，最貴的模型不一定最好

三種寫法：Mode A、B、C

  • Mode A：日常觀察，像跟粉絲聊天，例如麵包店老闆記錄「今天麵團發得比較快」
  • Mode B：成果分享，可以放結果，但不要一直發，會讓人覺得廣告味太重
  • Mode C：長文，用一個鉤子、一個矛盾、一個鮮明立場開頭，最容易破圈，讓原本不認識你的人看到你
  • F19公式：立場非常鮮明的寫法，支持你的人會來按讚，被你批評的人也會來吵，流量就起來了。要有心理準備，但只要做的是對的事就不用怕

發文前一定要做的三件事

  1. 檢查數字、時間、地點：JasonC分享過AI幫他撈資料、結果撈錯就直接上架的經驗。這一步不能省
  2. 像不像你：有沒有你平常不會說的話？平常很斯文的人，貼文突然很霸道，粉絲會接不起來
  3. 發完要看成效：先想清楚目標是「被更多人看到」還是「收到詢問」，兩者不一定能同時達成

JasonC很誠實地說，口氣調到像自己，可能要一到兩個月。剛開始先照框架走，比較快上軌道。

5. FB和Threads實測技巧（Hao0321分享）

Threads

  • 貼文不要放產品連結，觸及會降，也容易被當成行銷帳號
  • 最大的權重是轉推：有幾千粉絲的人轉推你，他的粉絲就會看到你。反過來，你一直幫別人轉推，流量會被分出去
  • 買藍勾勾，Hao0321實測沒有影響

FB

  • 想讓某個人看到你的文章：先去按讚他的貼文
  • FB加好友就等於互相追蹤，上限5000人
  • 用個人帳號發文，比較容易被認識，也比較容易開收益
  • 發到社團時，用「分享到社團」直接發成社團貼文，而且不要發影片，會觸發社團管理機制被警告

發文時間和格式

  • Hao0321的經驗是，尾數是4的時間點效果特別好，例如10:54、7:34，避開大家都在搶的整點
  • 有一種「四行四段」的格式：一行字、空一行，總共四行，搭配對的時間和關鍵字
  • 怎麼判斷一篇貼文成功：九成以上的觀看來自非追蹤者，代表平台有把你推出去
  • 最推薦的用法：先自己寫想法和草稿，再叫AI優化，寫出來才會是你想講的東西

6. 自由工坊平台導覽

  • 技能書：社群夥伴做的開源工具，按公會分類，可以直接拿來用
  • 作品上架：可以直接叫AI幫你上架，平台設計成AI讀得懂、操作得了
  • 找夥伴：用專長搜尋，例如搜n8n，就能找到會用n8n的夥伴
  • 供貨與分潤：有貨源的夥伴寫好願意分潤的比例，大家幫忙推廣，賣出就分潤，不用被大平台抽成
  • 平台已經內建Social Post的寫文優化（要接你自己的AI）；一鍵發文功能Hao0321建議先不要用

7. Editkin：為什麼要做一套剪輯軟體（Hao0321分享）

原始碼：Hao0321/Editkin

你可以叫Claude直接幫你剪影片，但有兩個問題：剪完不能修改，要改就得再燒一次token；而且同一個對話一直剪，快取會吃掉大量token。

  • Editkin的做法是把模板和底層都先寫好，再讓Skill去呼叫它。Hao0321說這樣一兩萬token就能剪完，還會留下可以修改的專案檔
  • 內建轉場、字卡、音樂素材，可以即時改字、改色
  • 當天展示的是舊版，有延遲；新版還在做
  • Hao0321也提醒：用Google的AI生成內容再發到YouTube要小心，Google的浮水印很容易被認出是AI做的

8. 開源授權入門（星語｜@YuStellar分享）

現在大家很常拿GitHub上的開源工具來改，所以授權變得很重要。星語｜@YuStellar把授權比喻成共享食譜：大家都能拿去煮，但要照作者定的規矩。

授權一句話
MIT最寬鬆：隨便用，只要不說是你自己寫的
Apache 2.0跟MIT差不多寬鬆，另外把專利和貢獻者的權利寫得更清楚
BSD介於兩者之間，現在比較少人選
GPL v3你用了它、改完發布，也要把原始碼公開
AGPL v3最嚴格：就算你只是做成網站服務，也要公開原始碼
CC授權適合文章、照片、影片這類內容，不適合拿來授權軟體
  • 開源不代表不能收費；反過來，網路上能下載也不代表可以隨便用
  • 授權會混合：程式可以是MIT，裡面用到的照片可能是CC，要分開看；也不能把別人GPL的東西改成MIT再發布
  • 最簡單的選法：想讓大家隨便用，選MIT或Apache 2.0；希望別人改了要分享回來，選GPL

  • Tripo 3D：丟一張圖就生成3D模型。做遊戲可以用面數低的模式，模型乾淨、好用；要3D列印就用高精度模式，還能直接送到印表機。當天Hao0321說談到社群合作，用合作連結註冊會多送點數（連結是隔天才發）
